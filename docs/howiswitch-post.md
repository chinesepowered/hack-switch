## LinkedIn (longer)

For the Flip the Switch hackathon I built CapyTales: a bedtime-story studio that lives in a family
chat.

One Switch room holds the family (a parent, a kid, a grandma) and four Claude Code agents, each a
capybara with one job: Mochi writes, Pebble draws, Yuzu narrates with ElevenLabs, Tofu binds a
read-along book and a story video.

What I liked about building on Switch:
• Addressing policies made the parental gate real: kids can ask for stories, but only a parent can
  tell Yuzu to read one.
• Agents hand off by @-mentioning each other, so the family sees every step.
• Files move as room attachments, and the family's "Story bible" is a room document, so tomorrow's
  story remembers tonight's.
• One template sets the whole thing up.
